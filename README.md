# Delivery Time Prediction (Multiple Regression)

A machine learning web application built with Flask and scikit-learn that predicts delivery times based on user inputs.

## Prerequisites
Before running this project, make sure you have Python installed along with the following libraries:
* Flask
* pandas
* scikit-learn

You can install all three at once using:
```bash
pip install flask pandas scikit-learn
```

## How to Run
1. Run the Python file in your terminal or code editor.
2. Click the `http://` link generated in the terminal output (usually `http://127.0.0.1:5000`).
3. Enter all the required delivery details into the form.
4. Click **Predict Delivery Time** to view your predicted delivery time.

---
> **DISCLAIMER:** This project is for educational purposes only. Predictions are generated by a sample machine learning model and may not reflect real-world delivery times.
